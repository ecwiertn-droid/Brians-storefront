# Home page photos

Drop real photos in this folder with these exact filenames and they'll
appear on the home page automatically — no code changes needed. Until a
file exists, that spot shows an animated placeholder instead of a broken
image.

| Filename | Shows in | Suggested shape |
|---|---|---|
| `hero-training.jpg` | Training / workout photo | Landscape, roughly 4:3 (e.g. 1200x900) |
| `hero-smoothie.jpg` | Smoothie / drink photo | Landscape, roughly 4:3 |
| `hero-coaching.jpg` | Coaching / consultation photo | Landscape, roughly 4:3 |

Keep each file under a few MB — resize/compress large phone photos first
(any free tool like squoosh.app works) so the page loads quickly.

You can add more photo slots the same way later — just tell me where you
want them and I'll wire up the matching filename.
